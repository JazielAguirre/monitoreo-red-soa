1Entrega 1 · Sistema de diseño y dashboard — pendiente de revisión
Acento añadido. --color-acento #2F6FB0 para foco, enlaces, gráfica y el pulso del ping: el azul marino no se distingue sobre la barra lateral.
Contraste AA. El punto usa el color de estado puro; el texto del badge usa una variante oscura (-texto), porque #22C55E sobre blanco no llega a 4.5:1.
Bootstrap primero. Espaciados = spacers de Bootstrap, alturas de botón/campo = 38 px, rejilla de 12 columnas. Las gráficas son referencia visual para Chart.js.
Prueba el dashboard. «Monitorear todos» recorre los dispositivos uno por uno; pasa el cursor por la gráfica para ver el tooltip; el menú celular se abre con ☰.
